不満を示した相手に、AIはどう謝るか

応対に不満を持った相手への返答を、3つのモデルに3種類の指示で書かせ、計90回答を人間1名とLLM評定者3名が評価しました。中心の問いは、ユーザーが作成した「不満への対応ガイド」をシステム指示に入れると、謝罪の質がどれだけ変わるかです。

要点1　対応ガイドの効果7 → 20 / 30回答

人間評価者が「十分」とした回答数（指示なし → 対応ガイド）。Claudeは1件から9件、GPTは3件から7件、Museは3件から4件に変化。

要点2　一般的な謝罪指示5 / 30　と　79 / 90票

「誠実に謝る」趣旨の一般的な指示は、人間評価では効果がなく（7件→5件）、LLM評定者からは3条件で最も高い評価を受けた。評価の向きが逆になった。

要点3　人間とLLM評定者の一致κ = 0.00

同じ回答に同じ評定を付けたのは90件中29件で、偶然に一致する水準と同じ。LLM評定者は延べ270票のうち「誠意なし」を一度も付けていない。

要点4　「謝罪で完結」の境界場面8

対応ガイドの「謝罪で応答を完結させる」指定は、態度や進め方を問われた場面で効いた。相手が次の行動のために現在地を尋ねた場面8では、謝罪だけで止めた回答が低評価になった。

平均文字数（指示なし → 一般指示 → 対応ガイド）：Claude 291 → 238 → 193、Muse 113 → 147 → 123、GPT 161 → 159 → 123

ただし、回答の長さそのものは人間評価と結びついていません。90回答を文字数で三等分すると、「十分」は短い群12件、中間10件、長い群10件です。対応ガイドのClaudeは同条件で最も長い（平均193字）にもかかわらず9件が「十分」でした。評価を分けたのは、謝罪の後に何を続けたかです。
